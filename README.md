# Boeing 737NG PTU MATLAB 教学演示

本项目用 MATLAB 演示波音 737NG 液压系统中动力传输组件（PTU）的工作逻辑。可通过预设工况或自定义输入，观察不同条件下 PTU 的工作状态。

## 快速开始

下载并解压本仓库，在 MATLAB 中将当前文件夹切换到 `.m` 文件所在目录。

运行交互式演示：

```matlab
PTU_Demo
```

运行适合 PowerPoint 展示的版本，可将 PTU 接替供油过程导出为 GIF：

```matlab
PTU_Demo_PPT
```

## 模型用途

本项目为课堂教学使用的简化模型，用于说明 PTU 的工作逻辑和供油过程。
